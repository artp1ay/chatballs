# Архитектура раскладки (Layout) в Chatballs на базе Consta UI

## 1. Внутренний интерфейс (Internal UI — Backoffice)

Интерфейс операторов и администраторов строится с использованием компонентов `Layout` из `@consta/uikit/Layout`.

### 1.1. Каркас приложения (Shell Layout)
```
+-----------------------------------------------------------------------------------------------+
| Layout (direction="row", fullHeight)                                                          |
| +-------------------+ +---------------------------------------------------------------------+ |
| | Sidebar           | | Layout (direction="column", flex="grow")                            | |
| | (240px / 64px)    | | +-----------------------------------------------------------------+ | |
| | - Логотип         | | | Header (56px) - Бренд, поиск, статус оператора, профиль         | | |
| | - Диалоги [Badge] | | +-----------------------------------------------------------------+ | |
| | - Клиенты (CRM)   | | | Content (flex="grow", overflow="hidden")                        | | |
| | - База знаний     | | |                                                                 | | |
| | - Интеграции      | | | [Рабочая зона выбранного маршрута: чат / таблица / форма]       | | |
| | - Сотрудники      | | |                                                                 | | |
| | - Настройки       | | |                                                                 | | |
| +-------------------+ +---------------------------------------------------------------------+ |
+-----------------------------------------------------------------------------------------------+
```

- **Боковая навигация (`Sidebar`):**
  - Поддерживает два состояния: развернутое (`width: 240px`) и свернутое в режим иконок (`width: 64px`).
  - Содержит логотип Chatballs, пункты меню с бейджами непрочитанных сообщений (`Badge label="3" status="error"`), блок быстрого онбординга и пользовательское меню внизу.
- **Верхняя панель (`Header`):**
  - Название активной организации, индикатор статуса оператора (В сети / Отошел / Не беспокоить), колокольчик уведомлений с вызовом `NotificationDrawer`, аватар текущего сотрудника.

---

### 1.2. Рабочее место оператора (Operator Workspace — 3-колоночный сплит)

```
+--------------------+-------------------------------------------+------------------------------+
| Список диалогов    | Лента активного диалога                   | Контекст клиента             |
| (320px - 360px)    | (flex="grow")                             | (340px - 380px)              |
|                    |                                           |                              |
| [Поиск...]         | [Шапка: Имя клиента, статус, звонок, опции] | [Tabs: Инфо | История | CRM] |
| [Tabs: Мои/Все/Оч] | ----------------------------------------- | ---------------------------- |
|                    | [Лента переписки]                         | Карточка клиента (Card):     |
| [Список диалогов]: | - Клиент: Здравствуйте, есть вопрос!      | - Имя, телефон, email        |
| - Клиент A (нов)   | - AI: Ответ сформирован [Принять/Править] | - Компания, тариф            |
| - Клиент B         | - Оператор: Отправлен ответ               | - Теги клиента (Tag)         |
| - Клиент C         | ----------------------------------------- | - Заметки оператора          |
|                    | [Composer: ввод ответа, шаблоны, отправка]| - Ссылка на сделку           |
+--------------------+-------------------------------------------+------------------------------+
```

1. **Колонка списка диалогов (320–360px):**
   - Поле поиска: `TextField size="s" placeholder="Поиск диалогов..." leftSide={IconSearch}`.
   - Фильтры очередей: `Tabs size="s"` (Входящие, Мои, Ожидают ответа, Закрытые).
   - Элемент списка диалога:
     - `Avatar size="m" name={clientName} form="round"`;
     - Имя клиента и источник (`Badge` Telegram, Web, WhatsApp);
     - Сниппет последнего сообщения (`Text size="s" view="secondary"`);
     - Таймстамп и счетчик новых сообщений (`Badge form="round" status="error"`).
2. **Центральная колонка переписки (`flex="grow"`):**
   - **Шапка диалога:** имя клиента, статус («В работе», «AI-агент»), кнопка перевода диалога (`Button view="secondary" size="s"`), кнопка аудио/видеовызова (`Button view="ghost" size="s"`).
   - **Лента переписки:**
     - Разделители дней: `Text size="s" view="secondary" align="center"`.
     - Сообщения клиента: левый край, фон `--color-bg-secondary`.
     - Сообщения оператора: правый край, фон `--color-bg-tone`.
     - Сообщения AI: плашка с бейджем `AI Agent`, возможностью редактирования перед отправкой.
     - Голосовые сообщения: аудиоплеер с waveform и длительностью.
     - Системные события: плашки `Informer view="system" size="s"`.
   - **Зона набора ответа (Composer):**
     - Поле ввода `TextField type="textarea" rows={2} maxRows={6} size="m"`.
     - Тулбар: быстрые шаблоны ответов (`/`), вложения (`IconAttach`), отправка `Button view="primary" size="s" iconRight={IconSend}`.
3. **Правая колонка контекста клиента (340–380px):**
   - Вкладки `Tabs size="s"`: «Инфо», «История обращений», «Заметки», «CRM».
   - Карточка клиента `Card`: контактные данные, теги `Tag size="s"`, назначенный оператор.

## 2. Клиентский веб-чат (Client Web Chat Widget & Call Stage)

### 2.1. Форм-факторы виджета
1. **Плавающий виджет (Desktop):**
   - Плавающая кнопка вызова (FAB): круглый элемент `56x56px`, `form="round"`, цвет бренда.
   - Всплывающее окно чата: фиксированный размер `380x620px`, отступ `20px` от краев, тень Level 3, скругление `radius-l` (`16px`).
2. **Мобильный режим (Mobile):**
   - Размер `100vw` x `100vh`, поддержка `safe-area-inset`.

```
+-------------------------------------------------------------+
| Web Chat Window (380x620px)                                 |
| +---------------------------------------------------------+ |
| | Header (Accent)                                         | |
| | [Avatar] Поддержка Chatballs                 [_] [^] [X] | |
| |          ● Онлайн                                       | |
| +---------------------------------------------------------+ |
| | Body (flex="grow", bg="--color-bg-secondary")           | |
| |                                                         | |
| | [12 мая]                                                | |
| | [Avatar] Здравствуйте! Чем помочь?                      | |
| |                                                         | |
| |                        Нужна помощь с интеграцией! ->   | |
| |                                                         | |
| | [Avatar] Печатает...                                    | |
| +---------------------------------------------------------+ |
| | [Баннер входящего звонка, если активен]                 | |
| +---------------------------------------------------------+ |
| | Composer                                                | |
| | [TextField: Сообщение...] [Скрепка] [Микрофон] [Послать]| |
| +---------------------------------------------------------+ |
| | Brand Footer: "Работает на Chatballs"                   | |
+-------------------------------------------------------------+
```

### 2.2. Модуль аудио/видеовызова (Call Stage)
- Доступен в отдельном окне (`/calls/:id`) или поверх виджета.
- Сетка видеопотоков участников с адаптивной компоновкой.
- Панель управления звонком:
  - Микрофон: `Button form="round" size="l" view="secondary"`;
  - Камера: `Button form="round" size="l" view="secondary"`;
  - Экран: `Button form="round" size="l" view="secondary"`;
  - Завершить вызов: `Button form="round" size="l" view="ghost" status="alert" iconLeft={IconPhoneEnd}`.
