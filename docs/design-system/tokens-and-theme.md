# Токены темы, палитра и типографика Chatballs

## 1. Архитектура пресета темы Consta UI

Темизация в Chatballs реализуется через корневой провайдер `<Theme preset={...} />` из библиотеки `@consta/uikit/Theme`. Пресет включает 5 модулей токенов: `color`, `control`, `font`, `size`, `space`.

Платформа поддерживает две темы оформления:
- **`presetChatballsDefault`** — светлая тема интерфейса.
- **`presetChatballsDark`** — тёмная тема интерфейса.

```ts
import { ThemePreset } from '@consta/uikit/Theme';

export const presetChatballsDefault: ThemePreset = {
  color: {
    primary: 'chatballsDefault',
    accent: 'chatballsAccent',
    invert: 'chatballsDark',
  },
  control: 'gpnDefault',
  font: 'gpnDefault',
  size: 'gpnDefault',
  space: 'gpnDefault',
};

export const presetChatballsDark: ThemePreset = {
  color: {
    primary: 'chatballsDark',
    accent: 'chatballsAccent',
    invert: 'chatballsDefault',
  },
  control: 'gpnDefault',
  font: 'gpnDefault',
  size: 'gpnDefault',
  space: 'gpnDefault',
};
```

## 2. Цветовая палитра и семантические токены

Использование прямых HEX-значений в стилях компонентов запрещено. Все стили связываются с CSS-переменными темы Consta.

### 2.1. Фирменный акцент (Brand Primary)
- **Светлая тема:** `#0070F0` (основной синий Chatballs).
- **Тёмная тема:** `#2985F8` (адаптированный оттенок повышенной яркости).
- Семантические переменные: `--color-control-bg-primary`, `--color-typo-brand`, `--color-bg-brand`.

| Роль токена | CSS-переменная Consta | Светлая тема | Тёмная тема | Назначение |

## 3. Типографика

Типографическая система базируется на компоненте `Text` из пакета `@consta/uikit/Text`. Запрещается прямое задание `font-size` в пользовательских CSS-классах.

### 3.1. Шрифтовой стек
```css
font-family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
```

### 3.2. Шкала типографики Consta `Text`

| Размер (`size`) | Line-height | Начертание (`weight`) | Назначение |
|---|---|---|---|
| `6xl` (36px) | 44px | `bold` | Крупные заголовки лендингов |
| `5xl` (32px) | 40px | `bold` | Заголовки первого уровня (H1) страниц |
| `4xl` (28px) | 36px | `semibold` | Заголовки второго уровня (H2) разделов |
| `3xl` (24px) | 32px | `semibold` | Заголовки карточек (H3), модальных окон |
| `2xl` (20px) | 28px | `semibold` | Шапка диалога, заголовок карточки клиента |
| `xl` (18px) | 24px | `medium` | Подзаголовки блоков, акцентные лейблы |
| `l` (16px) | 24px | `regular` / `medium` | Заголовок виджета чата, поля форм |
| `m` (14px) | 20px | `regular` / `medium` | **Базовый текст:** сообщения чата, таблицы |
| `s` (12px) | 16px | `regular` / `medium` | Подписи полей (`caption`), время, бейджи |
| `xs` (10px) | 14px | `regular` | Микро-счётчики в сайдбаре |
| `2xs` (8px) | 10px | `regular` | Технические маркеры |

## 4. Сетка, отступы, скругления и тени

### 4.1. Модульная сетка и шкала отступов (4px grid)
- `space-3xs`: **2px** (микро-зазоры между иконкой и текстом)
- `space-2xs`: **4px** (внутренние отступы бейджей)
- `space-xs`: **8px** (базовый межэлементный интервал форм)
- `space-s`: **12px** (отступ между полями формы, паддинг инпутов)
- `space-m`: **16px** (базовый паддинг карточек, сообщений и модалок)
- `space-l`: **24px** (отступ между смысловыми секциями страницы)
- `space-xl`: **32px** (отступ крупных контейнеров)
- `space-2xl`: **40px** (отступ блоков бэкофиса)
- `space-3xl`: **48px** (внешние поля экрана)

### 4.2. Скругления углов (Border Radius)
- `radius-xs`: **4px** (бейджи, тултипы).
- `radius-s`: **6px** (компактные поля ввода `size="s"`, всплывающие меню).
- `radius-m`: **8px** (**Базовый радиус платформы:** кнопки, поля ввода, карточки, модалки).
- `radius-l`: **12px** (контейнер виджета чата, контекстные панели).
- `radius-full`: **9999px** (аватары, круглые кнопки звонка, pill-фильтры).

### 4.3. Тени и глубина (Elevation)
- **Level 1 (Card):** `0 1px 3px rgba(0, 32, 51, 0.08), 0 1px 2px rgba(0, 32, 51, 0.04)` — карточки контента, строки таблиц при ховере.
- **Level 2 (Dropdown / Popover):** `0 4px 12px rgba(0, 32, 51, 0.12), 0 2px 4px rgba(0, 32, 51, 0.06)` — меню, селекты, поповеры.
- **Level 3 (Modal / Chat Widget):** `0 8px 24px rgba(0, 32, 51, 0.16), 0 4px 8px rgba(0, 32, 51, 0.08)` — модальные окна, плавающий веб-чат.
- **Level 4 (Toasts / SnackBar):** `0 16px 36px rgba(0, 32, 51, 0.20)` — всплывающие системные уведомления.
