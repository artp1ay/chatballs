# Дизайн-система Chatballs на базе Consta UI

## Обзор и назначение спецификации

Данный раздел содержит официальную дизайн-спецификацию платформы **Chatballs** при полном переводе фронтенда с библиотеки **Ant Design** на дизайн-систему **Consta UI** (`@consta/uikit`, `@consta/icons`, `@consta/header` и сателлитные пакеты).

Спецификация разработана Lead UI/UX Designer для продуктовой команды, frontend-разработчиков и QA-инженеров.

---

## Структура спецификации

Спецификация декомпозирована на специализированные модули:

1. **[Токены, темы и типографика](./tokens-and-theme.md)**
   - Архитектура пресетов Consta (`presetChatballsDefault`, `presetChatballsDark`).
   - Семантические токены цветов для светлой и тёмной тем.
   - Шкала типографики Consta `Text` и иерархия стилей.
   - Сетка (4px/8px), отступы (`space`), скругления (`radius`) и тени (`elevation`).

2. **[Архитектура раскладки (Layout)](./layout-architecture.md)**
   - Внутренний интерфейс оператора (`@chatballs/internal-ui`): каркас `Layout`, `Sidebar`, 3-колоночный сплит диалогов, контекст клиента.
   - Клиентский веб-чат (`@chatballs/web-chat`): плавающий виджет (FAB + Popup), полноэкранный режим, модуль аудио/видеовызовов (`CallStage`).

3. **[Каталог компонентов и интерактивные состояния](./components-mapping.md)**
   - Полный каталог соответствия (маппинг) компонентов Ant Design → Consta UI.
   - Интерактивные состояния элементов (Default, Hover, Focus, Active, Loading, Disabled, Alert).

4. **[Пользовательские сценарии и передача в разработку](./user-journeys.md)**
   - UX-сценарий оператора: обработка обращения, контекст, шаблоны, AI-ассистент.
   - UX-сценарий клиента: обращение через веб-виджет, мультимедиа, аудиосообщения, звонок.
   - Поэтапный план реализации и критерии готовности (Definition of Done).

## Ключевые принципы дизайн-системы

1. **Использование нативных паттернов Consta:** Отказ от избыточных CSS-оверайдов и самодельных компонентов в пользу стандартных решений `@consta/uikit`.
2. **Семантическая строгость:** Исключение "магических чисел" и сырых HEX-кодов; все значения берутся из токенов темы.
3. **Бесшовная адаптивность:** Одинаково продуманное поведение на мониторах операторов (Desktop) и смартфонах пользователей веб-чата (Mobile).
4. **Доступность (Accessibility):** Контрастность не ниже WCAG 2.1 AA, видимый фокус с клавиатуры (`focus-visible`), поддержка скринридеров через ARIA-атрибуты Consta.
